# Welcome to Fortress Notes

This is a plain Markdown file in your `notes/` folder. Edit it here, or in any other
editor — the app just reads and writes these files.

## Try it

- Click **+ New** to create a rough note.
- Toggle search between **full-text** and **embedding** (ColBERT late-interaction).
- Open a note and watch **Related notes** refresh in the bottom-left.
- Use the **AI** button to fact-check, ask clarifying questions, or raise objections.
- Promote a **rough** braindump into a **polished** note when it's ready.
